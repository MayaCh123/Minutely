# 🎙️ Minutely

Minutely is an AI-powered app that turns your curiosity into personalized 5-minute podcast episodes—generated with OpenAI and ElevenLabs.

## 🚀 Features
- Smart topic suggestions
- Deep Dives
- Curiosity Roulette
- Time Traveler Mode
- Adjustable Complexity & Mood
- Active Recall Quizzes
- Wrapped Analytics & Listener Persona

## 🛠️ Setup Instructions

1. Clone this repository
2. Create a `.env` file with your keys:
OPENAI_API_KEY=your_openai_key_here
ELEVENLABS_API_KEY=your_elevenlabs_key_here
3. Install dependencies:
pip install -r requirements.txt
4. Run the app:
streamlit run app.py
